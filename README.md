## 📖 **Overview**

**COSMIC-324** is an advanced, open-source space mission simulation and orbital tracking platform. It is designed to be a sovereign alternative to expensive commercial tools like STK and GMAT, integrating:

- 🌍 **3D Keplerian Orbital Dynamics** with **J2 Perturbation** (Earth oblateness effect) for high-precision orbit propagation.
- 🛰️ **Hybrid Predictive Routing** for dynamic satellite constellation management.
- 📡 **Real-time Data Fetching** from Celestrak (supports up to 5000 satellites).
- 📶 **6G Spectrum Analysis** (S-Band, Ku-Band, Ka-Band, 6G-THz) with jamming simulation.
- 🧠 **AI-Driven Optimization** for constellation design and mission planning.
- 🚀 **Propulsion & Maneuver Engine** (Hohmann transfer, inclination change) with ΔV calculation.
- 🛸 **Debris & Collision Risk Assessment** for space situational awareness.
- ☀️ **Space Weather Integration** (solar activity impact on atmospheric drag).
- 💰 **Commercial Pricing Tiers** (Basic, Pro, 6G Titan X) for scalable business models.

| Feature | Description |
| :--- | :--- |
| **3D Constellation Globe** | Interactive 3D Earth globe with satellite positions and ground station. |
| **Live Telemetry Table** | Real-time data on satellite status, latitude, longitude, and altitude. |
| **Signal Latency Evolution** | Tracks and visualizes latency with adjustable alert thresholds. |
| **Mission Pre-Planning** | Simulate future satellite maneuvers and assess collision risks. |
| **Spectrum Analyzer** | Visualize 6G frequency allocation and simulate spectral jamming. |
| **Performance Mode** | Toggle between Full Resolution (5000 sats) and High Speed (100 sats). |
| **Auto Refresh** | Automatically update live data at customizable intervals. |
